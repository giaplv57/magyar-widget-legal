# magyar-widget-legal

Static Privacy Policy and Support pages for the Magyar Widget iOS app.

## Enable GitHub Pages
1. Push these files to the root of the `main` branch of public repo `giaplv57/magyar-widget-legal`.
2. Repo **Settings → Pages**: Source = **Deploy from a branch**, Branch = **main**, folder = **/ (root)**, Save.
3. Wait 1–2 minutes, then open:
   - https://giaplv57.github.io/magyar-widget-legal/
   - https://giaplv57.github.io/magyar-widget-legal/privacy.html
   - https://giaplv57.github.io/magyar-widget-legal/support.html

Use `privacy.html` as the App Store Connect Privacy Policy URL and `support.html` as the Support URL.
